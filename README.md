# Cursor Landing Page Clone

This project is a pixel-perfect, desktop-first recreation of the Cursor AI editor landing page. It is built strictly using plain HTML and CSS, adhering to all specified constraints.

## Sections Recreated

The following 11 sections have been successfully built to match the original design structurally and visually:

1. **Top Navigation Bar**: Features the logo, dark background, links, and right-aligned CTA buttons.
2. **Hero Section**: Includes the main headline, "Download for macOS" CTA, and a prominent product screenshot.
3. **Trusted By / Logos**: A row representing company trust badges.
4. **Feature Sections**: Three distinct blocks detailing features, utilizing a two-column alternating layout (text and image).
5. **Feature Cards Section**: A 3-column grid highlighting specific aspects of the editor like Privacy Mode, VS Code Extensions, and the AI Terminal.
6. **Testimonials**: Quote cards detailing user feedback with author names and roles.
7. **Use Cases / Stories**: Clean cards detailing scenarios like Refactoring, Debugging, and Onboarding.
8. **Changelog / Updates**: A styled list displaying the most recent updates alongside dates.
9. **Team / About**: A distinct section incorporating the provided text about "Introvert" and displaying company statistics, utilizing an inverted color scheme for emphasis.
10. **Final CTA**: A large, centered call to action to download the product.
11. **Footer**: Multi-column links encompassing product, resources, company information, and copyrights.

## Typography and Colors

**Fonts Used:**
The project uses the `Inter` font family sourced from Google Fonts, falling back to system sans-serif fonts (`-apple-system`, `BlinkMacSystemFont`, `Roboto`, `Helvetica`, `Arial`). This closely mimics the modern, clean, highly-legible aesthetic of the original site.

**Color Palette:**
The layout precisely implements the provided hex codes:
*   **Rangitoto (`#26251E`)**: Used as the primary background color for the body and navigation, establishing the required dark theme.
*   **Cararra (`#F7F7F4`)**: Used for the primary text color, primary buttons (e.g., Download), and the background of the "About" section for high contrast.
*   **International Orange (`#F54E00`)**: Employed as an accent color for interactive hover states on text links.

## Usage Instructions

1.  Clone this repository to your local machine.
2.  Open the `index.html` file in any modern web browser to view the page.
3.  As per the requirements, the page is optimized for **desktop viewing** (min-width: 1024px) and does not include responsive tablet or mobile styles.
